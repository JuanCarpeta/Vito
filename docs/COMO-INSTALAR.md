# Cómo instalar Vito (versión resumida para el paquete)

> La guía completa vive en el README del repositorio:
> https://github.com/JuanCarpeta/Vito

1. Doble clic sobre `instalar.bat`
   (instala Ollama si falta y descarga el modelo `llama3.1:8b`, ~4.9 GB, una sola vez).
2. Doble clic en `vito.exe`. Listo.

Si algo falla: la ventana no se cerrará sola; lee el mensaje y abre Ollama
desde el menú de inicio (ícono de llama) antes de abrir Vito.
